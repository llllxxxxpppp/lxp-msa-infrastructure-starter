REST API의 주요 특징 3가지만 요약해줘.

smart_toy

REST API의 주요 특징은 다음과 같습니다:

  1. 무상태성(Stateless): 각 요청은 독립적이며 서버는 클라이언트의 상태를 저장하지 않습니다.
  2. 캐시 가능성(Cacheable): 응답 데이터는 캐시되어 네트워크 비용을 줄일 수 있어야 합니다.
  3. 계층화 구조(Layered System): 클라이언트는 서버의 중간 계층(프록시, 게이트웨이 등)을 알 필요 없이 통신할 수 있습니다.
